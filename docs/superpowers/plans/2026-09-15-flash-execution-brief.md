## 一、课题与目标

正式题目：**长程软件开发任务中智能体持续执行机制研究——以 Claude Code 为观察对象、以开源 Harness 为实验载体**。

导师用自然语言多轮迭代一个思维导图应用，提出了一个研究问题：为什么这类智能体能在不断修改需求、使用工具、修复错误和中断恢复之后继续推进一个软件项目？

本研究采用：Claude Code 行为观察 → 官方资料与固定版本源码解释 → 固定模型的受控机制消融 → 一项证据支持的扩展。

主实验只操纵两件事：结构化跨阶段状态是否可用；开发阶段测试反馈是否可用。四个条件是 C00、C10、C01、C11。模型、任务、阶段消息、工具接口、资源上限和重启节点保持一致。

不要声称能从 dsh 代码直接知道 Claude Code 的内部实现。把事实分成官方说明、开源源码、本次观察、解释假设四类。
