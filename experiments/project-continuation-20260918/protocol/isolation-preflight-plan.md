## 4. 凭据与评价资产边界

- 产品正常认证属于可信客户端行为；被测产品的**生成代码**运行在无 secret 环境、独立身份与独立执行域中。
- 若客户端必须与不可信代码共享可读的认证目录，则 A、B 两方案均不合格；不得声称"VM 天然满足凭据不可达"。
- hidden evaluator 不与不可信代码共享可写环境；验证一律使用替身资产，不读取实际 hidden 用例或真实凭据。
- 无凭据读写、无真实评分资产读取，是预检通过的前提。

## 5. 路径与网络测试设计

最小替身布局（仅未来计划）：由受信任控制方建立任务根下的 `allowed/`、根外 `outside-canary/`，以及模拟 `credential-canary/`、`evaluator-canary/`，写入非敏感随机内容并记录这几个精确文件的基线哈希。受限执行身份只获 `allowed/` 的权限。VM 路线在客体内同样分隔可信认证/评价方与生成代码身份，宿主 canary 不挂载；宿主不可达还需通道配置证据，不能用“路径不存在”代替隔离证明。

路径测试（正负对照）：
- 阳性：合法域内路径读写成功。
- 阴性：`..` 相对路径出界、任务内符号链接出界、canary 目录/文件读写拒绝。
- 对上述替身分别做读、写、创建/删除尝试并记录拒绝；域外文件精确白名单哈希前后不变。文件不变只证明未修改，不证明无法读取，必须另有读取被拒绝的证据。不扫描真实凭据/评价目录。
- 拒绝必须由真实 OS/VM 隔离机制施加，而非脚本 if 判断。

网络测试：
- 本轮不做任何公网探测。
- 未来验证使用任务自控的合成监听目标/隔离网段：先由可信控制方确认目标可达，再让受限父/子/孙进程尝试并验证拒绝；服务端无接收记录结合执行域拒绝日志，不能单凭连接超时认定隔离。覆盖声明禁止的出站、入站/本地入口；未测范围列未知，不连接真实外部服务。

进程测试：
- 子进程带孙进程测试网络/文件约束继承。
- 超时必须杀掉完整子树。
- 限任务精确 PID/创建时间定位，不扫描全机进程。

**不计为通过：** 本机空壳脚本自称 deny、干跑、普通子进程"成功"，均不构成完整隔离证据。
