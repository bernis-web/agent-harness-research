# 思维导图（T1 参考实现）

本目录是 T1 冻结规格（`../spec/T1-规格-冻结-v1.0.md`）的参考实现（由执行者 AI 依据冻结规格编写，来源见上级目录准备说明），用于在运行环境获批后验证"规格可满足性"，并作为评价器的对照基准。**它不是被测产品任务工作空间的一部分，不得复制进产品工作空间。**

## 打开方式

- 双击 `mindmap.html`，用 Chrome 或 Edge 最新版打开即可；纯本地单文件，无服务端、无构建、不联网、不加载任何外部资源。

## 用法

1. **生成**：左侧文本框按"每行一个节点、行首 2 空格＝1 层、第一条非空有效行顶格为根"的格式输入，点击"生成导图"。有非法行（缩进跳层、含 Tab、有效首行不顶格、奇数缩进、多根）或空白行全部忽略后无有效行（空输入）时整体拒绝并提示，导图与撤销记录不变；生成成功＝整体替换当前导图并清空撤销记录。空白行（零长度或仅空白字符）一律忽略；Tab 为非法字符（首部/中间/尾部均拒绝）。
2. **编辑**：每个节点提供"重命名 / +子节点 / 删除"按钮。删除连同全部后代（删根＝清空整图）；编辑只影响目标节点及其子树；空标题的编辑被拒绝（状态不变、不进撤销记录）。
3. **撤销**：每点一次回退最近一次编辑，删除可整体恢复；至少连续 10 次；到底后再点无效果不报错；生成与导入不可撤销；无重做。
4. **导出 JSON**：将当前导图导出为 `{"title", "children"}` 结构的 JSON 文件（浏览器默认下载行为，是否弹出保存对话框视浏览器设置而定）；无导图时拒绝。
5. **导入 JSON**：经文件选择对话框显式选择 JSON 文件，校验通过后整体替换并清空撤销记录；解析失败、结构或标题不符均整体拒绝且状态不变；取消选择静默忽略。应用不自动发现或加载任何本地文件。
