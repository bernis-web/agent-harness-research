# 计划 03:长期记忆的注入策略(Memory Injection Policies)

> 定位:定量实验 | 难度 ★★ | 周期 3-5 周 | 产出:四种记忆注入策略对比报告
> 对应课程子方向:记忆管理、上下文管理

## 一、研究意义

长期记忆系统已经是红海:Mem0、Letta(MemGPT)、Zep、Cognee 等都解决了"记什么、怎么存、怎么检索"。但被忽视的一环是**读侧:记忆以什么形式、在什么时机注入上下文**——这恰恰是 harness 层的决策(写入与检索可以外包给记忆系统,注入策略属于上下文组装)。同一个记忆库,开场全量注入、每轮检索注入、滚动摘要注入,效果与成本可能差异巨大,还会引入"记忆干扰"(过时记忆诱发错误)。

本计划固定记忆写入策略,只对比注入策略,回答:harness 应该怎样把长期记忆"喂"给模型。这是六大子方向中实验成本最低、结论最直接的一个,适合作为科研实践的第一个定量实验。

## 二、研究现状及实验室研究基础

- **记忆系统脉络**:MemGPT(2023,OS 隐喻:上下文=RAM、存储=硬盘)→ Letta(Core/Recall/Archival 三层);Mem0 生产级 API(官方论文报告在单跳/时序/多跳基准领先);学术前沿 A-MEM(NeurIPS 2025,记忆网络自主演化)、RMM(ACL 2025,反思式记忆管理)。
- **注入侧现状**:Letta 的 core memory 常驻窗口、Mem0 默认"检索后拼进系统提示"——各框架默认值不同,但无人做过受控对比;Deep Agents 的 Checkpointer(线程内)+ Store(跨线程)提供了干净的实验接口。
- **实验室基础**:Python + deepagents(Store 接口)+ DeepSeek API;可用公开长对话基准 LoCoMo 或自建多会话任务;无 GPU 需求。

## 三、研究内容及研究计划

### 3.1 研究内容

1. **多会话任务集**(20-30 条轨迹):一个"用户"与智能体跨 5-8 个会话互动,埋入三类可考察事实——稳定偏好(总用中文回复)、时变事实(第 3 会话换了工作)、一次性事件(第 2 会话提到养了猫)。考察问题分单跳/时序(新事实覆盖旧事实)/多跳(组合两条记忆)。
2. **记忆写入(固定)**:每会话结束后统一用相同流程抽取事实写入存储(向量库),四种策略共享同一份记忆库,排除写入差异。
3. **四种注入策略**:
   - I0 无记忆(基线);
   - I1 开场全量:会话开始把全部相关记忆拼入系统提示;
   - I2 每轮检索:每轮按当前输入检索 top-k 记忆附加;
   - I3 滚动摘要:维护一份"用户画像摘要",每会话更新,常驻窗口。
4. **指标**:三类问题准确率;token 成本(注入开销);记忆干扰率(被过时事实误导,专设陷阱题:问"现在"的工作);时延(检索带来的轮内延迟)。
5. **分析**:策略×题型交互;注入量 k 的敏感性(I2 中 k∈{3,5,10});画像摘要的信息压缩损失。

### 3.2 周计划(5 周)

- W1:任务集与陷阱题设计;记忆抽取流程实现(固定)。
- W2:四种注入策略实现(基于 deepagents Store 或自建轻量 harness,复用计划 01 的 agent loop 更佳)。
- W3:主实验(4 策略 × 全部轨迹)。
- W4:k 敏感性消融;错误案例分析(过时记忆如何压过新事实)。
- W5:撰写报告与"harness 记忆注入实践建议"。

### 3.3 预期产出与验收标准

- 产出:任务集、实验代码、策略×题型准确率表、案例分析、实践建议。
- 验收:每策略覆盖全部轨迹与三类题型;对"时序题哪一策略最稳"给出显著性与案例支撑。

### 3.4 风险与退路

- 风险:LoCoMo 等公开基准答题污染(模型见过)→ 优先自建任务集,公开基准仅作参考复测。
- 风险:记忆抽取质量波动 → 抽取后人工抽检 20%,必要时全量人检(量小可行)。
