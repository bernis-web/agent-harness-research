## 推荐组合(学期主线)

- **稳妥型**:04 做底盘(源码理解 → 全部后续工作的基础)+ 01 或 03 做一个定量实验。
- **底层型**(最贴合课程"稍微底层"要求):04 + 07,或 04 + 01/07 合并("压缩策略对缓存与保真度的双重影响")。
- **视野型**:04 + 05,回答"什么时候值得用多智能体"这个争议问题。

## 更远的延伸方向(开阔视野用,不必现在做)

1. **Agent OS 形式化**:把 harness 与操作系统做严格对应(调度=agent loop、内存层级=记忆/上下文、文件系统=虚拟文件系统、系统调用=MCP、进程隔离=子代理、日志文件系统=事件溯源),写成立场论文。
2. **Harness 独立基准**:控制模型不变、只换 harness 组件的评测协议——目前行业空白。
3. **RL 优化 harness 策略**:把"何时压缩、何时检索记忆、何时派子代理"建模为策略学习问题(已有零星工程尝试,学术空间大)。
4. **协议互操作实测**:MCP 与 A2A 双协议下的跨厂商智能体协作真实打通度测试。
5. **神经符号记忆**:向量记忆 + 知识图谱 + 文件工作区的混合记忆结构比较。
